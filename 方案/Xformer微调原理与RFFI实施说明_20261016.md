# Xformer 微调原理与 RFFI 实施说明

版本：2026年10月16日。用途：作为现有《Xformer低信噪比RFFI实验方案》的学习与实施补充。当前内容属于研究计划和代码核查结论，尚不代表微调实验已经完成。

当前建议是：先使用配对 WVD 数据，对灰度预训练 Xformer 做有监督的全参数微调，以 L1 恢复损失建立基线；随后加入设备身份约束。部分冻结、LoRA 和 Adapter 放在后续对照中，根据验证表现与实际资源需求决定是否采用。这个顺序不代表全参数微调已被证明最好。

## 研究任务与模型起点

我们的处理流程为：

原始 IQ → IQ 域加噪 → WVD 时频表示 → Xformer 降噪 → ResNet18 → 设备身份。

要解决的问题是低信噪比下设备的细微射频指纹被噪声淹没。最终判断依据是设备识别效果，PSNR、SSIM 等恢复指标提供辅助证据。图像看起来干净，不等于设备差异保留得好。

本地单通道灰度权重 xformer_blind_gray_dn.pth 约有 2522 万个可学习参数。它是一个千万参数级图像恢复网络。含有 Transformer 并不意味着必须采用语言大模型常用的微调配方。训练资源还受到输入尺寸、激活特征、batch size 和优化器状态影响，必须在实际 GPU 上测量。

自然图像与 WVD 都可以表示为二维数组，因此接口可以衔接。但 WVD 的时间轴、频率轴有不同的物理含义，其负值、交叉项、数值范围和噪声统计与普通照片不同。IQ 域加入 AWGN 后再做 WVD，也不等于直接给图片像素加独立白噪声。预训练是否有用，需要通过实验验证。

## 微调究竟在修改什么

神经网络有一套确定的计算结构，还有一套通过训练得到的参数。Xformer 的第一层卷积核、STB 的 QKV 投影、CTB 的点卷积和深度卷积、BCU 的卷积、恢复部分和输出层，都包含可学习参数。

作者用自然图像训练后，这些数值已经共同形成了一套恢复能力。微调就是保留这套参数作为起点，用无线领域样本继续校正它。

可以想象一个已经会修复照片的人开始学习处理时频图。他已经掌握一些恢复规律，但还需要学习新领域中哪些结构应该保留、哪些扰动应该抑制。

| 概念 | 参数从哪里开始 | 在本项目中的含义 |
| --- | --- | --- |
| 从零训练 | 随机初始化 | 用无线数据从头学习恢复能力 |
| 预训练 | 在前一个数据或任务上训练 | 作者先在自然图像上训练 Xformer |
| 微调 | 从已有训练权重开始 | 用我们的 WVD 继续学习 |
| 直接推理 | 加载后不更新 | 直接用自然图像模型处理 WVD，作为对照 |
| 恢复训练 | 从自己中断的训练状态继续 | 同时恢复对应模型、优化器、调度器等状态 |

全参数微调仍然利用预训练。所有权重可以改变，不等于把它们重新随机初始化。迁移到新的任务时通常加载模型权重、重新建立优化器；恢复同一次中断训练才恢复相应优化器状态。

还要区分“参数”和“中间计算结果”。QKV 投影矩阵、卷积核属于学习参数；一张图生成的 Q、K、V 和注意力矩阵，是由输入与当前参数计算出的中间结果。微调改变参数，下一次生成的注意力分配也随之改变。

窗口大小、网络层数、头数、学习率等属于配置或超参数。常规微调不会自动把窗口尺寸训练成另一个整数。

## 一次微调如何发生

先取同一个实测 IQ 包，准备一对数据：

- 不额外加入噪声，计算 WVD，得到实测参考。
- 在 IQ 域加入指定强度噪声，再计算 WVD，得到含噪输入。

实测参考仍可能包含采集时的噪声，不是严格的无噪声真值。

训练过程依次为：

1. 前向计算：把含噪 WVD 输入 Xformer，得到恢复结果。
2. 计算损失：比较结果与同包参考，得到误差。
3. 反向传播：计算可训练参数对误差的影响，即梯度。
4. 优化器更新：根据梯度、学习率和优化器规则调整参数。
5. 更换样本，重复上述过程。

例如，仅观察三个位置：

| 项目 | 位置一 | 位置二 | 位置三 |
| --- | ---: | ---: | ---: |
| 实测参考 | 0.2 | 0.6 | 0.9 |
| 模型输出 | 0.3 | 0.5 | 0.8 |
| 绝对误差 | 0.1 | 0.1 | 0.1 |

平均绝对误差为 0.1，这就是 L1 损失的简化例子。实际会比较整张图和整个 batch。

梯度告诉优化器，在当前样本和参数附近，改变一个参数会怎样影响损失。它不直接给某个通道贴上“频偏”“设备指纹”的标签。各层通过共同调整，逐渐学出有助于训练目标的特征组合；单次更新也不保证所有样本都改善。

## 微调类型应从三个角度区分

| 问题 | 常见选择 | 当前选择 |
| --- | --- | --- |
| 用什么信号指导训练 | 配对恢复监督、设备标签监督、自监督等 | 先用配对恢复监督 |
| 哪些参数允许更新 | 全参数、部分冻结、LoRA、Adapter | 先全参数 |
| 降噪器与分类器怎样组织 | 分阶段或联合训练 | 先训降噪器，再固定它训练分类器 |

所以，“有监督”与“LoRA”不是二选一。有监督训练也可以采用 LoRA。我们第一阶段可准确称为“有监督的跨领域全参数微调”。

## 全参数微调

全参数微调让所有可学习参数都有机会改变，包括卷积、注意力投影、可学习归一化参数、BCU 和恢复部分。允许更新不代表每个参数变化同样大；实际变化由梯度和优化过程决定。

它适合作为我们的第一条基线，有三个理由。

首先，自然图像到 WVD 的差异可能从输入层就存在。低层数值、局部结构和坐标含义都发生变化，不能预先认定浅层完全通用。

其次，我们恢复的是整张时频图。早期提取什么、中间如何交互、后面如何恢复，都可能影响弱指纹线索。如果早期表达已经压掉某个差异，仅调整末端不一定能补回来。

最后，保留原结构、统一数据协议，只改变初始化和微调过程，比较容易解释收益来自哪里。

代价是需要为更多参数保存梯度和优化器状态，并控制过拟合。全参数微调适合作为基线，需要小步更新、验证集和明确的停止规则；不能承诺它一定优于冻结或 LoRA。

## 部分冻结与逐步解冻

部分冻结保留指定参数，只训练其余部分。例如固定编码部分，训练解码和输出部分。也可以开放输入层与恢复部分，固定其余模块；这些是不同的实验设置，必须分别记录。

“冻结”的含义是参数不更新。冻结层仍处理输入，对不同输入仍输出不同结果。它不会变成一个固定输出的模块。

冻结可以减少一部分参数训练开销，也限制了模型的可调整范围。但“前面的层永远通用，所以一定全部冻结”不适合直接套到 WVD 迁移。

本地灰度 Xformer 的最终输出层为无偏置的 3×3 卷积，权重形状为 1×96×3×3，共 864 个权重。只训练它主要调整最终特征组合，适配能力受限，因此不作为首选主方案。

逐步解冻是先训练选定部分，再开放更多层。它可以用于控制适配过程，但引入了额外的阶段和学习率设置。首轮无需同时增加这些变量。

实现中需要明确：

- requires_grad=False 用于固定参数；优化器只纳入可训练参数。
- eval() 改变某些层的运行行为，不等于冻结参数。
- 冻结层前面如果还有可训练模块，梯度可能仍需穿过冻结层，不能自动把它包进 no_grad()。
- Xformer 的部分底层模块在两分支之间共享，不能把同一套共享参数当成两套独立参数来冻结。

## LoRA 的原理和适用边界

原线性变换可以写作 y=Wx。全参数微调直接改变 W。LoRA 固定原来的 W，学习一个低秩增量：

y = Wx + B(Ax)

等价地，W_new = W + BA。这里省略实际实现中的缩放系数，方便理解。

以 48 维到 48 维的投影为例，假设 LoRA 秩为 4：

| 参数 | 形状 | 数量 |
| --- | --- | ---: |
| 固定的原矩阵 W | 48×48 | 2304 |
| 可训练矩阵 A | 4×48 | 192 |
| 可训练矩阵 B | 48×4 | 192 |

这时新训练的参数共 384 个。原来 48 维主计算仍然存在；新增分支经过 4 维后映射回 48 维，给原输出提供修正。这里的 4 是我们设置的秩，限制了修正量能表达的变化范围，并非把原模型所有特征压成 4 维。

Xformer 可研究的适配位置包括 STB 的 qkv、proj 线性层，以及 CTB 的 qkv、project_out 点卷积。当前本地实现没有直接启用 LoRA 的配置开关，不能照搬语言模型 q_proj、v_proj 的层名。适配注意力投影也不会自动训练输入卷积、深度卷积或 BCU。

LoRA 的直接收益是减少可训练参数、对应梯度和优化器状态，并便于保存多个任务的增量权重。完整模型仍要前向计算，中间激活和梯度传播仍可能占用较大显存。可训练参数少十倍，不意味着总显存或运行时间也减少十倍。

当全参数微调的优化器开销突出、需要多个日期或接收机的适配版本，或出现值得研究的过拟合现象时，可以比较 LoRA。它的低秩约束可能有帮助，也可能限制大幅领域适配，需要验证。

## Adapter 与 QLoRA

Adapter 保留原网络，在其中插入小型可训练模块，用新增模块完成适配。它与 LoRA 都属于参数高效微调，但改变网络的方式不同。新增模块的位置和规模也需要确定。

QLoRA 将冻结底座量化，并训练低秩适配部分，以进一步节省资源。其原始研究面向大型语言模型。应用到我们的恢复网络，还需要核对卷积等算子支持、数值稳定性和恢复效果。现阶段不把量化加适配作为首选，以免在基线尚未跑通时同时引入新的误差来源。

## 恢复损失与设备身份约束

微调哪些参数，只决定调整范围。训练数据与损失决定调整方向。

假设结果 A 与参考整体更接近，但把设备间细微差异平滑掉了；结果 B 的整体误差稍大，却仍能准确区分设备。仅用 L1 时，模型未必偏好 B，因为 L1 没有直接表达设备身份的重要性。

第一阶段使用：

L_rec = mean(abs(D_theta(T_noisy) - T_ref))

D_theta 是 Xformer，T_noisy 是含噪 WVD，T_ref 是同包实测参考。这一阶段的恢复损失不需要设备标签。训练结束后固定降噪器，再在其输出上训练 ResNet18，判断恢复是否有助于识别。

第二阶段可以使用：

L_total = L_rec + lambda × CE(C_ref(D_theta(T_noisy)), y)

y 是真实设备标签，C_ref 是预先训练的参考分类器。第一项要求接近同包参考，第二项要求保留可识别的设备信息，lambda 控制两项的相对作用。

参考分类器用训练划分训练、验证集选模型；随后固定其参数并设为 eval，但保留身份损失通过分类器传回 Xformer 的梯度。不能将整个教师前向放入 no_grad()。验收时，教师参数应不变，Xformer 应能收到有限、非零的身份损失梯度。

身份损失也可能使输出迎合教师。因此需要独立训练的评价分类器，并检查高 SNR 和参考输入下的识别是否受损。设备识别改善也不直接证明某一种具体硬件缺陷得到保留，后者需要物理测量或专门分析。

给 lambda=0 也追加相同训练预算，并给 SCUNet 相同身份目标作为控制，才能区分额外训练、损失设计和网络结构的影响。

## 数据量与过拟合

当前计划参照论文 B，选择同一天、同一接收机、10 个发射机，每个 800 个包，按 8:1:1 划分。训练原始包为 6400 个。

每包生成 8 档 SNR 可得到 51200 张图，但这些图仍来源于 6400 个原始包。它们增加的是噪声变化，不等于增加八倍独立采集场景。

数据少会增加过拟合风险，单日实验也限制结论的适用范围；这并不能单独证明千万参数模型无法微调。预训练提供的起点可能降低从零学习的负担，也可能出现负迁移。

必须先按原始包划分，再生成不同 SNR 和噪声实例。同包所有派生样本只能出现在同一划分。归一化统计只从训练集获得。验证和测试噪声实例固定，使模型比较可重复。

WVD 的时间和频率轴意义不同，不直接照抄自然图像的 90 度旋转、翻转或任意裁剪增强。增加人工噪声实例不能替代跨日期、跨接收机和真实信道多样性。

| 观察到的现象 | 优先检查或解释 |
| --- | --- |
| 训练误差下降而验证误差持续上升 | 可能过拟合，检查预算、学习率和数据多样性 |
| 训练与验证误差都异常 | 检查权重加载、样本配对、数值范围、梯度和优化设置 |
| PSNR 提高而识别下降 | 恢复目标可能没有保护设备判别信息 |
| 同日好而跨日差 | 采集条件泛化不足 |
| 预训练微调不如随机初始化 | 检查加载和适配，也可能存在负迁移 |

## 本项目拟定实施顺序

| 阶段 | 做什么 | 如何检查 |
| --- | --- | --- |
| 接通数据与模型 | 构造 IQ 加噪后的 WVD 配对数据，严格加载灰度模型 | 标签、同包配对、划分、维度和数值范围正确 |
| 单样本验证 | 前向、小样本反向、保存重载 | 输出形状正确，损失与梯度有限，重载输出一致 |
| 短程运行 | 全参数加 L1，先 500 次参数更新 | 记录显存、速度、训练与验证误差 |
| 第一批基线 | 不降噪、SCUNet 微调、Xformer 微调 | 同划分、同噪声、同分类预算 |
| 原因对照 | Xformer 直接推理与随机初始化训练 | 区分微调和预训练的贡献 |
| 身份保持 | L1 加身份损失及相同追加预算控制 | 独立分类器验证低 SNR 收益 |
| 参数效率 | 部分冻结、LoRA 等 | 同协议比较识别、显存、参数量与时间 |

现有方案的第一阶段起点为 Adam、学习率 1e-4、有效 batch 4。先物理 batch 1，累积 4 次后更新一次；500 次更新用于试跑，正式上限暂定 20000 次更新。按现有方案执行固定子集和完整验证集的 L1 验证与选模；最终研究效果仍以识别指标判断。

第二阶段从 L1 权重继续，学习率拟为 1e-5，追加最多 5000 次更新。lambda 从 0.01、0.1、1 起步，并保留 lambda=0 控制。候选按验证集低 SNR 识别、参考与高 SNR 保持情况，以及恢复误差选择。应同时检查两项损失的梯度规模，不能仅凭数值看起来相近选权重。

这些是现有计划的起点，不是已验证最优超参数。短程试跑不稳定时，可以通过验证比较更小学习率；正式改动须同步记录配置和选模规则。

## 常用训练术语

| 术语 | 含义 |
| --- | --- |
| 学习率 | 优化器更新权重时的步幅系数 |
| 物理 batch | 一次前向和反向实际处理的样本数 |
| 梯度累积 | 多个小批次计算梯度后，统一更新一次参数 |
| 有效 batch | 单次更新汇总的样本数；本计划单卡 1×4=4 |
| 更新 step | 优化器实际修改一次参数 |
| epoch | 按事先定义遍历一轮训练数据 |
| checkpoint | 某个训练时刻保存的模型状态 |
| 早停 | 验证表现长期无改善时提前结束 |

20000 次更新不是 20000 个 epoch。采用梯度累积时，一次小批次计算不一定对应一次更新。若每个原始包每轮出现一次，并随机选择一个 SNR，应明确这是一轮 6400 个样本，不是完整遍历 51200 个派生版本。

梯度累积计算损失时需要按累积批次数缩放，最后不足一组时也需正确处理。它能降低物理 batch，但不会降低单个样本的激活需求。含 BatchNorm 的分类器还需要考虑真实 batch 的统计行为，不能把累积直接等同于大物理 batch。

## 正式训练前的代码核查

首选单通道 blind 灰度权重：
Xformer-rffi/experiments/pretrained_models/xformer_blind_gray_dn.pth。

其首层权重为 48×1×3×3，输出层为 1×96×3×3，可接单通道 WVD，无需复制成 RGB。权重与源码的静态核对不等于实际通过 PyTorch 严格加载和前向检查。

当前灰度测试脚本采用 CTB 块数 [2,4,4]、STB 块数 [2,4,4,6]，与现有权重结构相符。上游 blind 灰度训练 YAML 中 num_blocks 为 [4,6,6,8]，不能只改权重路径就当作已经匹配。必须按实际权重建立结构，以 strict=True 加载，不用宽松加载掩盖不匹配。

上游自然图像数据加载器的图像加噪、几何增强和图像数值处理也不能直接用于 WVD。需要专用配对浮点数据管线，记录 WVD 网格、补齐与裁回方式、归一化统计及 data_range。

实际显卡型号和显存需查询。先测小 batch 的完整训练步，再决定混合精度、梯度累积、激活重计算和分辨率。参数量、梯度、优化器状态与中间激活共同占用显存；LoRA 不保证解决由大特征图主导的资源问题。

## 评价与证据范围

主要报告八档 SNR 的设备准确率和宏平均 F1，以及低 SNR 混淆矩阵。低 SNR 平均准确率定义为：

[Acc(-6) + Acc(-4) + Acc(-2) + Acc(0)] / 4。

检查参考输入和高 SNR 表现，避免降噪损伤本来可识别的特征。PSNR、SSIM 在明确数值表示与固定 data_range 下计算；必要时报告 MAE、NMSE，但不能将 WVD 域指标称为 IQ 恢复指标。

核心结论至少用三个训练种子复核。测试集不参与选超参数。同包的多个 SNR 版本不是独立观测。随机初始化在相同预算下未收敛时，应如实表述比较范围。

## 论文事实与来源

论文 B 第 4 页明确使用迁移学习微调预训练 SCUNet，Adam、学习率 1e-4、batch 4。没有明确交代冻结哪些层，因此不能断言作者采用全参数或只训末层。分类阶段的 100 iterations 也不能直接解释为降噪器训练 100 个 epoch。

论文 A 的自然图像训练采用 AdamW、初始学习率 3e-4、300k iterations 和渐进 patch/batch 等设置。这是原任务训练配置，不能当成无线微调必须照搬的预算。
